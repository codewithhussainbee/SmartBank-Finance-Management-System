# 🏦 SmartBank Finance Management System

### Smart Financial Management, Simplified

A modern full-stack banking and finance management system built for educational purposes. It provides authentication, account management, simulated money transfers, transaction tracking, expense management, budgets, reports, notifications, admin controls, and AI-based anomaly detection.

## 🚀 Live Demo

**SmartBank Finance Management System**  
https://smart-bank-finance-management-syste.vercel.app/

## ✨ Features

- 🔐 User Authentication
- 👤 Account Management
- 💸 Simulated Money Transfers
- 📜 Transaction History
- 💰 Expense & Income Tracking
- 📊 Budget Management
- 📈 Financial Reports & Analytics
- 🔔 Notifications
- 🤖 AI Fraud/Anomaly Detection
- 🛡️ Admin Dashboard

## 🛠️ Tech Stack

**Frontend:** React, Vite, Tailwind CSS, Axios, Recharts  
**Backend:** Node.js, Express.js, REST API, JWT  
**Database:** MongoDB, Mongoose, MongoDB Atlas  
**AI:** Python, FastAPI, Scikit-learn, Pandas

## ⚠️ Disclaimer

This is an **educational project**. It does not connect to real banks or process real money. All financial transactions are simulated.
